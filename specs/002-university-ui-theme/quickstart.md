# Quickstart: Apply University UI Kit Theme

## Prerequisites

- Node.js and npm installed.
- Project dependencies installed (`npm install`).
- Local access to the named University UI Kit Figma Community reference when inspecting exact visual details.

## Validate the application

1. Run `npm test` and confirm all existing domain behavior tests pass.
2. Run `npm run build` and confirm the local production bundle is generated in `dist/`.
3. Serve `dist/` with a local static server and open each route listed in `PROTOTYPE.md`.
4. At viewport widths 360px, 768px, and 1280px, inspect campaign, applications, and schedule screens for theme consistency, readable content, usable controls, and no horizontal scrolling.
5. Exercise the existing application decision and schedule conflict/confirmation behavior; confirm that visual changes did not alter outcomes.
6. Compare displayed campaign dates, identities, statuses, schedule rows, and totals with `checks/shared-fixtures.md`.
7. Run the project's HTML validation process and record actual outcomes in the existing check/evidence documents.

## Expected outcome

All nine screen/viewport combinations remain usable and consistently themed; routes, fixtures, and representative workflow outcomes are unchanged. Record any blocked reference access or validation limitation rather than claiming an unperformed check.
